# ИМТ — лендинг Origin v2

Новая визуальная версия лендинга. Текст главной страницы, кроме заменённого блока объяснения, сохранён из s1.5, коммит `ebf063929c2047264a9827197681ec895ee11592`. Полная страница Концепции обновлена по мастер-версии от 2 октября 2026 года. Этот репозиторий развивается независимо от предыдущей версии.

## Запуск и проверка

Требуется Node.js 20 или новее. Установка пакетов не нужна.

```sh
cd site
npm run dev
```

Для подготовки публикационной папки:

```sh
npm run release
```

Команда собирает обе страницы, проверяет ссылки, локальные ресурсы и сохранность текста, затем обновляет `docs/`. В GitHub она ничего не отправляет. GitHub Pages публикует `docs/` из единственной рабочей ветки `main` после отправки коммита.

## Где менять

- `content/landing.json` — исходный контент лендинга s1.5.
- `content/full-text.md` — точная копия мастер-версии Концепции от 2 октября 2026 года.
- `content/full-text-source.json` — дата, контрольная сумма мастер-файла и соответствия прежних якорей. При следующем обновлении полного текста нужно обновить и эти сведения.
- `site/src/origin.css` — активные стили Origin для обеих страниц и мобильной версии.
- `site/scripts/origin-design.mjs` — композиция первого экрана и первой схемы.
- `site/scripts/build.mjs` — генерация разметки.
- `site/src/main.js` — мобильное меню, масштабирование графики.
- `design/assets/` — локальная графика Figma, схемы и шрифты Inter с лицензией OFL.
- `design/origin-asset-manifest.json` — происхождение ресурсов Figma.
- `docs/` — готовый сайт, также можно открыть `docs/index.html` локально.

Предыдущие дизайн-материалы оставлены как история проекта; `site/src/style.css` и `design/tokens.json` не управляют текущим оформлением. Актуальные стили — только `origin.css`.

## Визуальный источник и ограничения

Использована только страница **Origin** [указанного файла Figma](https://www.figma.com/design/fnW1d68r8ZVXFEdEuzcD1u/?node-id=27-5). Первый экран, блок объяснения и первая схема опираются на фрейм `27:5`. Остальные секции и полный текст оформлены в том же визуальном языке с сохранением текста главной страницы; полный текст Концепции следует актуальной мастер-версии. Доступ к дополнительным фреймам остановился из-за лимита Figma MCP; полного попиксельного соответствия всей страницы другим фреймам не заявляем.

Публичный репозиторий содержит только сайт, не базу знаний GEMS. Это предложение для обсуждения, не действующий государственный стандарт.

## Полная страница Концепции

Оглавление строится из мастер-текста: введение, 13 разделов и два приложения. Текущий раздел подсвечивается при прокрутке; левое меню прокручивается, чтобы активный пункт оставался видимым. Круглая полупрозрачная кнопка «Наверх» появляется после прокрутки на высоту первого экрана. Анимация учитывает системную настройку уменьшения движения. Прежние якоря `m1`–`m12` и вложенные якоря сохранены как переходы к соответствующим темам новой редакции.

Внешние ссылки из приложения Б сохранены. В публичной странице приложения Б оставлены только нормативные документы; блок «Авторские и рабочие материалы» исключён при сборке. Исходная мастер-версия в `content/full-text.md` сохранена целиком. Ссылки на внутренние Markdown-материалы без публичных адресов показаны как названия с пояснением при наведении. База знаний не включена в сайт.
