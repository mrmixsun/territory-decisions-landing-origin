# Веб-прототип Концепции

Статический сайт без внешних зависимостей. Исходные тексты берутся из `../content/`, графика и дизайн-токены — из `../design/`; в этой папке находятся только код сайта и результат сборки.

## Локальный просмотр

Из папки `site/`:

```sh
npm run dev
```

Откройте адрес, который появится в терминале (по умолчанию `http://localhost:4173/`). После изменения исходных текстов, графики или стилей перезапустите команду.

Основной текст лендинга хранится в `../content/landing.json`. Читаемая версия обновляется командой `npm run export:copy`; прежние редакции находятся в `../content/versions/`.

## Готовая статическая версия

```sh
npm run build
npm run check
```

Готовые файлы находятся в `dist/`. Внутренние ссылки относительные: папка работает как в корне сайта, так и по пути репозитория GitHub Pages. Для публикации в этом отдельном репозитории обновите `../docs/` содержимым `dist/` и отправьте изменения в `main`. Команды сборки сами ничего не отправляют в GitHub.

Сейчас GitHub Pages берёт статические файлы из `../docs/` ветки `main`. Абсолютных путей от корня домена сайт не использует; отдельная переменная базового пути не требуется.

## Архитектура

- `../content/landing.json` — тексты главной страницы и подписи.
- `../content/full-text.md` — рабочая полная версия. Сборка преобразует её в `concept.html` и создаёт устойчивые якоря `m1`…`m12`.
- `src/origin.css` — активные цвета, типографика, сетка и адаптивные правила Origin.
- `../design/assets/` — редактируемые SVG; копируются в `dist/assets/` без растрирования.
- `src/` — разметка/стили/небольшой скрипт меню.

Рабочий акцент — оранжевый из Origin. Подготовить проверенную сборку в `docs/` можно одной командой `npm run release`. Исходники контента s1.5 проверяются на сохранность относительно коммита `ebf0639`.
